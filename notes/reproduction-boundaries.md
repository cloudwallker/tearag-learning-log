# 复现范围与结论边界

当前阶段是 **TeaRAG 的 R0 低资源流程适配**。官方源码固定在 `802e859950425390156fee8251c1ae0dcc6e0df4`，本地独立实现仍有以下差异。

| 部分 | 当前设置 | 结论限制 |
|---|---|---|
| 生成模型 | Llama 3 8B Q4_0 | 未加载 TeaRAG 训练权重，停止行为不等同于论文模型 |
| 训练 | 未执行 SFT/IP-DPO | 未复现训练结果 |
| 检索 | BM25 | 词法匹配不能代表原编码器与重排的语义召回 |
| 语料 | 每题 HotpotQA 原始 distractor 段落 | 非完整开放域检索 |
| 三元组 | 每段最多 2 个，文本受预算限制 | 可能遗漏关系和限定信息 |
| 图排序 | 保留来源的知识关联图与 PPR；边权使用词法代理分数 | 不能假定排序与官方一致 |
| 动作格式 | 结构化 JSON search/answer | 提示协议与官方不同 |
| 上下文 | 当前轮证据优先，保守字节预算装入 | 过滤与装入造成的遗漏需要分开记录 |
| 成本 | 包括每题三元组抽取，无跨题缓存 | 不是预建图部署后的摊销成本 |

## 数据与指标

训练流程集是作者 HF 数据集的前 30 行，属于非均匀的顺序样本。开发集从完整 7,405 条 distractor dev 记录中固定抽取 500 条，再划分为 150/350；它们是项目内部校准和留出分区，不是官方测试集。

开发 JSON 来自[公开镜像](https://huggingface.co/datasets/namlh2004/hotpotqa/blob/main/hotpot_dev_distractor_v1.json)。已做首尾抽查并记录文件哈希，但没有完成与作者官方原始文件的全量对照。

当前答案 EM/F1 采用 [HotpotQA 官方答案评测规则](https://github.com/hotpotqa/hotpot/blob/master/hotpot_evaluate_v1.py)，未报告 supporting-facts 或 joint 指标。三题运行只用于确认流程；新增诊断接口没有实际执行，因此不能报告纠错率、伤害率或新增收益。

## 仍待解决的问题

审计需核实遗漏 ID 确属当前或历史已选证据，且打包截断 ID 应对应实际缩短的可见文本。两者未充分校验时，损坏轨迹可能造成错误的压缩损失汇总。

打包截断集合应是实际缩短集合的子集，而非与之相等：证据在装入提示之前可能已按字符上限裁剪。修复与集成测试尚未完成。

关于停止的机制结论需要同一前缀上的配对比较，以及冻结方法后的独立留出评估。当前没有证据说明固定回看或自适应策略优于原流程。
