## 这阶段学到的内容

- 检索候选、PPR 选中候选和实际进入模型提示的证据是三个对象，分析遗漏时需要分别记录。
- 一个文本块被过滤后，同源三元组可能仍被保留；同源关系不能证明全部关键事实都保留下来。
- 成本统计需要包括三元组抽取和所有回答调用。本次逐题重新建图，不能把这部分成本解释为部署时已经摊销的成本。
- 严格答案不匹配可能来自表述差异；一次检索后回答错误，也不足以认定模型过早停止。

## 验证状态与后续任务

基础实现最后记录的完整测试为 28 项通过。新增审计、回看和分支模块分别通过了 9、7、10 项合成测试，这些数字不能合并宣称为最终集成验收结果。

审计仍有一项已知问题：遗漏和截断 ID 可能与证据来源或实际文本缩短不一致。下一步先补负例并修复校验，再独立审阅分支模块的最后修改，完成合成集成检查。

机制研究计划比较四组：接受原停止、回看一个过滤文本块、共同上限内追加一次检索、使用同样证据仅重新回答。实际配对执行与选择性触发规则的校准仍待开展。
